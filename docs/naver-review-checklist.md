## 현재 구현과 경계

현재 선택 ID/PW 가입은 유지했다. 가입 후 `/profile` 등록과 분리할지는 후속 결정한다.
네이버 토큰을 저장하지 않으므로 연결 해제 구현 방식도 별도 결정이 필요하다.
제공자 mock 테스트는 실연동 증빙이 아니다. 관리자 OTP와 `/service` 보호는 유지한다.
소셜 키 쌍이 없으면 로그인/추가 연결 버튼은 숨기며 기존 연결은 읽기 전용 표시만 가능하다.

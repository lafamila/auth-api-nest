# 네이버 로그인 검수 후속 목록

2026-11-18 업데이트. 공개 방침·동의·소셜 가입 분리·해제/탈퇴 코드는 반영했다.
**아래 운영 확인·키 설정·배포·검수 신청은 별도이며 실제 통과로 표시하지 않는다.**
출처: [공식 연동 가이드 PDF](https://developers.naver.com/inc/devcenter/downloads/naveridro/naverlogin_solo_guide.pdf).
가이드 기준 검토이며 법률 판단이나 승인 보장이 아니다.

## 추가 준비

- [ ] 수집 정보·이용 목적·개발자센터 권한·화면의 대응 확인, 불필요한 수집 제외. (p.4–5, 13–14)
- [ ] 방침 공개: 수집·목적·보유·파기·위탁·권리 행사·담당자·시행일 확인. (p.6–7)
- [ ] 가입 전 방침 열람, 필수/선택 동의 구분. (p.7, 16–17)
- [ ] 탈퇴·네이버 연결 해제·정보 삭제/익명화·세션 폐기 동선 검토. (p.11–12, 17)
- [ ] **소셜 가입 중 별도 PW 수집 검토.** 가이드의 반려 사유와 대조. (p.15–16)
- [ ] 네이버 subject 식별과 이메일 기반 기존 계정 연결을 구분해 검토. (p.5, 11, 18)
- [ ] 공식 로그인 버튼의 문구·색상·비율 확인. (p.7, 15)
- [ ] 실연동·동의 거절·이메일 미제공·계정 연결·재로그인·탈퇴/해제 검증. (p.11–12, 17)
- [ ] 제출 캡처: 로그인, 가입 전체 순서, 정보 사용처, 방침. (p.12–13)
- [ ] 공개 URL·callback·앱 로고·검수 중 가용성 확인. (p.13, 15)
- [ ] 운영 HTTPS·쿠키·state·서버 측 비밀 처리 확인. (p.11, 17)
- [ ] 휴대폰 정보·국외이전·전자상거래·승인 앱 변경은 해당하는 경우만 서류/고지/재검수 검토. (p.5, 13–14, 16, 18–19)

## 현재 구현과 경계

소셜 가입의 ID/PW 입력은 제거했고, 가입 후 `/profile`에서 선택 등록하도록 분리했다.
네이버 철회용 토큰은 서버에 암호화해 보관하고 해제·탈퇴 시 외부 해제 작업을 수행한다.
공개 소개·방침·약관·문의와 footer/A 로고, 버전별 명시적 확인, Auth 데이터 범위만
삭제하는 탈퇴 및 외부 철회 수신도 구현했다. 아직 실연동 증빙·검수 승인을 뜻하지 않는다.
제공자 mock 테스트는 실연동 증빙이 아니다. 관리자 OTP와 `/service` 보호는 유지한다.
소셜 키 쌍이 없으면 로그인/추가 연결 버튼은 숨기며 기존 연결은 읽기 전용 표시만 가능하다.
현행 배포 선행사항과 제공자별 남은 작업은 [운영 준비](./social-production-readiness.md)를 따른다.
